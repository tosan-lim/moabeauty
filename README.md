# MOA Beauty WordPress custom code

This repository contains the site-specific WordPress code for MOA Beauty.

Tracked code:

- `wp-content/mu-plugins/` — site-specific must-use plugins
- `wp-content/plugins/s-welcome-dashboard-6xF8hz/` — custom dashboard plugin
- `wp-content/themes/astra-child/` — active child theme

WordPress core, third-party plugins/themes, uploads, backups, caches, logs,
database configuration, and generated files are intentionally excluded.

Do not commit credentials or make direct code changes on the live server.
